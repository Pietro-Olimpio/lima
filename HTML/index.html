Categorias de conteudo HTML5

Elementos de bloco

ocupam toda largura disponivel, exemplo: <div><p><h1>, <select>, <article>

Elementos de linha

Ocupao apenas o espaço necessário na linha, exemplo: <a><span><strong>, <em>, <img>

Regras importantes

Elementos de linha não devem conter elementos de bloco

Phraseing content

Elementos que marcam textos ou partes de textos

<span> um bloco generico, nao muda nada sozinho, porem pode aplicar CSS ou chamar funções/comportamento com JavaScript

<a> Para anexar/criar links, utilizando o atributo href. Exemplo: clique para conhecer o bitcoin

<strong> deixar uma parte do texto em negrito

<em>deixa o texto em italico

<mark> serve para Marcar uma parte do texto

<img>importar imagem, desenho, foto (não precisa de tag de fechamento)

Embedded content

Utilizado para inserir um conteudo externo

<img>importar imagem, desenho, foto (não precisa de tag de fechamento)

<video> para adicionar um video(pode mostrar botões de play e pause)

<canvas> cria uma tela em branco que pode ser usada pelo JavaScript

<svg> vai desenhar graficos baseados em vetores

<iframe> coloca outra pagina inteira dentro do seu website (muito usado para adicionar mapas e videos)
