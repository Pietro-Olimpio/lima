# Sintaxe em html
##### O `header` no html serve para colocar um cabeçalho de uma página.
ex:
```html
<header>
    <h1>Teste</h1>
    <p>Isso é um teste</p>
</header>
```
--- 

##### Ja o section separa o conteudo em partes.
ex:
```html
<section>
    <h2>Seja bem-vindo!</h2>
    <p>um teste de escrita</p>
</section>
```
--- 

##### main
ja o main é onde fica o conteudo principal da pagina
ex:
```html
<main>
    <section>
        <h2>Seja bem-vindo!</h2>
        <p>teste de escrita</p>
    </section>

    <section>
        <h2>Fala com a gnt</h2>
        <p>teste de escrita</p>
    </section>
</main>
```
--- 
O main indica:

>"Aqui está o conteúdo mais importante dessa página."

Normalmente, deve existir um <main> principal por página.

##### Dar cor 
Para darmos cor a uma frase ou titulo utiliza-se:
```html
<h1 style="color: red">Hello Word!!</h1>
```
nesse exemplo o titulo "Hello Word!!" sera exibido em vermelho
